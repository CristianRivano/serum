# Entregables

- [x] Arquitectura React reutilizable con estado centralizado para los controles, historial de undo/redo y navegador de presets.
- [x] Motor Web Audio API con voces polifónicas, mixer dedicado, dos buses FX, routing de efectos en serie/paralelo y tres splitters L/H, L/M/H y M/S.
- [x] Tres osciladores principales con modos wavetable, sample, multisample, granular y spectral; carga de archivos de audio y buffers de fallback.
- [x] Warping FM, PM, ring modulation, phase memory, controles de dual warp y selector para PD/distorsión.
- [x] Hasta 10 LFO con formas sine, triangle, square, random, Lorenz y Rossler, con rutas editables en la matriz de modulación.
- [x] Cuatro envolventes ADSR con BPM e invert, además de amplitud y modulación de filtro.
- [x] Matriz de modulación editable con source, destination, amount y curve.
- [x] Filtros duales con routing en serie/paralelo y controles de cutoff, resonance, drive y mix.
- [x] Arpegiador con modos UP, DOWN, UP/DOWN, RANDOM y CHORD, rate, gate y tempo.
- [x] Clip sequencer de 16 pasos con edición, velocity visual y reordenamiento drag-and-drop.
- [x] Teclado virtual con transposición, selección de escala, swing y oscillator mapping.
- [x] Rack FX con los 13 tipos de efectos: Bode, Chorus, Comb, Compressor, Convolve, Delay, Distortion, EQ, Filter, Flanger, Phaser, Reverb y Utility.
- [x] Interfaz oscura inspirada en Serum 2, responsive y visualmente coherente.
- [x] Build Vite validada, rutas declaradas en manus-routes.json y diagnósticos JavaScript/CSS/JSON registrados.
- [ ] Biblioteca de presets y sonidos predefinidos con búsqueda, categorías, descripciones y carga instantánea de parámetros sonoros.
- [ ] Optimización de controles y layout para dispositivos móviles y pantallas táctiles.
- [ ] Verificación de la versión publicada en `https://rivano.click/serum/` después del despliegue.
