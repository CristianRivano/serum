# Entregables

- Arquitectura React reutilizable con estado centralizado para todos los controles de la interfaz.
- Motor Web Audio API con voces polifónicas, osciladores, envolvente ADSR y filtro en tiempo real.
- Osciladores A, B y sub con formas de onda, afinación, nivel y paneo ajustables.
- LFO con forma, velocidad, profundidad y destino de modulación audible.
- Distorsión y delay con activación y parámetros de mezcla, tiempo y realimentación.
- Macros y teclado virtual con interacción por puntero y respuesta visual.
- Interfaz oscura inspirada en Serum 2, responsive y visualmente coherente.
